# SportBorrow Playwright tests

ชุดทดสอบนี้ตรวจเว็บไซต์ `https://sportborrow.inprojex.tech/` ด้วย Google Chrome ผ่าน Playwright ผลแต่ละครั้งจะเขียนลง `playwright-report/` และ `test-results/results.json` ส่วนภาพหน้าจอ วิดีโอ และ trace จะเก็บเมื่อกรณีทดสอบไม่ผ่าน ผลรันเต็มวันที่ 28 ตุลาคม 2026 เก็บแยกไว้ใน `outputs/sportborrow_20261028/full-test.log` และ `full-run-record.json` เพื่อไม่ให้การรันครั้งถัดไปเขียนทับหลักฐาน

## ติดตั้งและรัน

```powershell
npm install
npx playwright install ffmpeg
npm run test:public
```

การทดสอบส่วนสมาชิกและผู้ดูแลระบบใช้ตัวแปรสภาพแวดล้อมดังนี้ โดยไม่บันทึกรหัสผ่านในโปรเจกต์:

```powershell
$env:SB_MEMBER_EMAIL = '<member email>'
$env:SB_MEMBER_PASSWORD = '<member password>'
$env:SB_ADMIN_EMAIL = '<admin email>'
$env:SB_ADMIN_PASSWORD = '<admin password>'
npm test
```

การรันเต็มชุดจะเข้าสู่ระบบครั้งเดียวต่อบทบาท แล้วใช้ session ที่เก็บชั่วคราวใน `.auth/` สำหรับแต่ละกรณีทดสอบ ลบ `.auth/` หลังใช้งานหากไม่ต้องการเก็บ session ไว้ในเครื่อง

กรณี `TC-057` รันซ้ำได้เมื่อมีลิงก์รีเซ็ตใหม่ โดยกำหนด `SB_RESET_LINK`, `SB_RESET_EMAIL` และ `SB_RESET_NEW_PASSWORD` ในสภาพแวดล้อมก่อนรัน `npx playwright test tests/prerequisites.spec.js -g TC-057` ลิงก์ต้องเป็นของบัญชีทดสอบและใช้ได้ครั้งเดียว

เว็บไซต์จำกัดความถี่ของการเข้าสู่ระบบ หากพบข้อความ `ทำรายการบ่อยเกินไป` ให้เว้นช่วงก่อนรันใหม่

## ผลการทดสอบล่าสุด

รายงานวันที่ 28 ตุลาคม 2026: ผ่าน 57 กรณี, ไม่ผ่าน 1 กรณี, ติดข้อจำกัด 3 กรณี จากทั้งหมด 61 กรณี ผลรวมนี้รวมการทดสอบ Playwright แบบโต้ตอบที่ต้องใช้ OTP และลิงก์จากอีเมลหลังการรันชุดหลัก ผลสรุปอยู่ใน `C:\Users\User\Downloads\SportBorrow_testcase.xlsx` และภาพหลักฐานใน `test-results/` รายงาน HTML/JSON ปัจจุบันเป็นผลการสั่งแสดงรายการทดสอบภายหลัง จึงให้ดูไฟล์ log ที่เก็บแยกไว้สำหรับผลรันเต็ม

การสมัครสมาชิกพร้อม OTP (`TC-056`) และการเปิด 2FA ด้วย TOTP (`TC-058`) ผ่านแล้ว การกู้รหัสผ่าน (`TC-057`) พบปัญหา: ผู้ที่ยังไม่ล็อกอินเปิดลิงก์จากอีเมลแล้วถูกส่งกลับหน้า Login แม้จะตั้งรหัสผ่านใหม่ได้เมื่อเข้าสู่บัญชีทดสอบก่อน และเข้าสู่ระบบด้วยรหัสใหม่ได้ ไฟล์สลิปทดสอบมีอยู่ แต่ `TC-059` ต้องมีค่าปรับค้างชำระของบัญชีทดสอบก่อน ส่วน `TC-060` กับ `TC-061` กระทบข้อมูลหรือผู้ใช้รายอื่น จึงระบุเป็น Blocked ในรายงาน

ทดสอบ `TC-057` ซ้ำเวลาประมาณ 18:00 น. วันที่ 28 ตุลาคม 2026 ด้วยบัญชี QA และลิงก์ใหม่แล้ว ยังถูกส่งกลับ `/login` ในหน้าต่างที่ไม่ล็อกอิน โดย `/api/auth/me` และ `/api/auth/refresh-token` ตอบ 401 ทั้งคู่ ลิงก์เดียวกันตั้งรหัสผ่านได้หลังล็อกอิน จึงยืนยันว่าปัญหาไม่ได้เกิดจากลิงก์หมดอายุหรือการจำกัดความถี่ บัญชี QA รอบทดสอบซ้ำถูกลบแล้ว
